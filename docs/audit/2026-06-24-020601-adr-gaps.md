1. Charset/decode unified policy — H, medium. One forward rule (detection-priority chain + reliability gate) tools cannot enforce ("single-byte never trusted"). Subsume the dangling BR/FR rule codes.
2. Output-injection defense (Markdown/YAML/javascript:) — H, medium. Cross-cutting "all untrusted text MUST route through these escapers"; unenforceable by type/lint; zero ADR coverage; security-load-bearing.

5. Signal exit codes 130/143 + graceful drain — H, medium. Public CLI exit-code commitment outside sysexits ADR-0002/0003.
6. GitHub token precedence + stderr drop — H, medium. Forward precedence + security contract (gh stderr dropped to avoid echoing token).
7. Env-var fail-fast + range-clamp discipline — M, high (incomplete-contract). "New tunables MUST fail-fast on invalid, never silent fallback"; candidate 14 merges in.
8. Search default output = one URL/line — H, high. OUTCOME.md-tied public output compatibility commitment for AI-agent consumers.
9. CDP launch egress-hardening flags — H, low. "Any new egress-capable flag must be evaluated vs proxy-bypass"; security forward rule; fix the dangling spec.md ref.
