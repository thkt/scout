## Skill Design Feedback

`/audit-adr-drift` 試運転で発見した skill 改善点:

1. **External ADR reference 検出**: skill は scout repo の `docs/decisions/` 内 ADR しか scan していない。code 内に `ADR-NNNN` 形式の参照があれば、それが scan 対象 ADR ディレクトリに存在するか cross-check すべき。今回は `ADR-0065` が scout に無いことに気付いたが、これは ugrep 結果を目視で確認した結果。skill 内に自動 check ステップを入れると良い。

2. **`/audit-undocumented` との連携**: audit-undocumented で `per ADR-NNNN` 参照を発見したら、それを「External ADR dependency」候補として記録すべき。本 audit (drift scan) で発見した ADR-0065 関係は、本来 audit-undocumented の段階で見つかるべきだった。

3. **Sub-decision 認識**: ADR-0065 は 2 つの decision (JSON schema + sysexits) を内包。ADR-0002 は片方だけを subset 化。skill は「ADR が複数 sub-decision を持つ場合の subset/superset 関係」を検出する仕組みが必要。
